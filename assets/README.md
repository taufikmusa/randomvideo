# Pustaka aset Taufik (@taufik.pg)

Guna semula aset ni untuk video / carousel / thumbnail. Jangan minta Taufik upload semula.

## Peraturan
- **Potret Taufik WAJIB ada outline putih (gaya sticker).** Jana: `sh assets/sticker.sh assets/taufik/<fail>.png <projek>/img/<fail>-sticker.png [tebal]`
- Watermark `@taufik.pg` pada setiap output.
- Gambar emas ada watermark G100 sendiri — biarkan.
- Potret = "selfie" Taufik: sentiasa ambil dari `taufik/`.

Anak panggil Taufik **Baba**. Guna nama panggilan sahaja dalam output (bukan nama penuh).
`sheets/` = helaian asal. Potong baru: `python3 assets/potong_sticker.py helaian.png assets/kartun/<watak> <prefix> 40 6` (bercantum? `60 16`), buang serpihan, namakan ikut pose.
