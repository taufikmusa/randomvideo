# GOLD — The Eternal Metal (60s, 9:16)

`gold-history.mp4` — 1080x1920, 30fps, 60s. History & impact of gold from Varna (4600 BC) to James Webb, cut to a 128 BPM procedural score that builds from pads → half-time → four-on-floor → snare-roll build → drop → finale.

Rebuild:
```
python3 music.py          # -> music.wav
node render.js            # -> gold-history.mp4 (needs playwright + ffmpeg)
node render.js stills 9 50  # preview frames
```
